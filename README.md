# CYSL · 团支部数字化建设体系工作台

> **在线访问 → https://icyteacn.github.io/CYSL-26CS/**

面向团支部的通用数字化工作台（纯静态 SPA，零构建），与 Android「智团慧建」App 数据模型互通。开箱即用于任意团支部——打开即用，全部数据存于使用者本机。

## 功能

- **首页驾驶舱**：支部建设指数环形图、三会两制一课雷达图、下次活动倒计时、规范度自动巡检提醒（可点击直达处理）
- **留痕台账**：12 类活动筛选/搜索、三件套（签到表+会议记录+归档）徽章、详情页扫码签到、关联立项证据链
- **活动月历**：按月浏览活动标记，点日期看当日留痕
- **入党日程**：全流程节点 + 批次时间线 + 材料清单勾选 + 避坑注意事项
- **团务知识库**："三会两制一课"制度、团章要点、发展团员流程、推优入党、智慧团建操作、主题团日指南
- **志愿服务**：时长排行 TOP10 图表、成员明细、按实登记
- **团支部立项**：申报表式字段（目标/立项依据/实施方案/成果）
- **成员管理**：增删改查、占位姓名、政治面貌/职务标记
- **建设体系**：制度落实进度、荣誉台账、一键生成年度建设报告（可打印/存 PDF）、JSON 备份恢复
- **官方公告**：`data/feed.json` 隐藏数据端点——更新该文件即可向所有 App/网页端推送通知与日程（免发版）
- **出片展示屏** `✦`：全屏深红金主题，自动轮播 + 实时时钟 + 滚动标语，支部大会/迎检投屏或全员手机对镜头
- **签到路由**：`#/checkin?e=<记录ID>`，与 App 生成的二维码配套

## 安全与隐私

| 机制 | 说明 |
|---|---|
| 数据本地化 | 全部数据存浏览器 `localStorage`，无任何服务器上传 |
| 占位姓名 | 初始为「团员01…26 / 青年01…08」，不含真实个人信息 |
| 三级身份 | 支委（可编辑，需口令）· 团员（查看+签到）· 群众/访客（只读） |
| 口令锁 | SHA-256 校验，初始口令由支委内部掌握，可在「体系」页修改 |
| 脱敏模式 | 一键开启后全站姓名显示为 `X**`，公开演示前建议开启 |

## 通用化部署

1. Fork 本仓库 → 修改 `assets/app.js` 顶部 `BRANCH` 常量为你的支部名
2. Settings → Pages → Source 选 **GitHub Actions**（工作流已内置，push 到 `main` 自动部署）
3. 推送 `data/feed.json` 的更新即可向所有端发公告/日程

## 本地预览

任意静态服务器：`python -m http.server` / `npx serve`。

## 移动客户端（2026-11 新增）

仓内新增两套**完全独立**的客户端源码，与网页共用同一份 `data/state.json` + `data/feed.json`（canonical 统一库，团员端只读）：

| 目录 | 技术栈 | 用途 |
| --- | --- | --- |
| `app-uniapp/` | Vue3 `<script setup>` + uni-app | HBuilderX 云打包 iOS（ipa） |
| `mp-weixin/` | 微信原生 WXML/WXSS/JS/JSON | 微信小程序上架 |

- 四页：动态（公告+全量统计+近期安排+立项进展）/ 留痕（按类型筛选）/ 成员（名册+志愿时长+荣誉墙，**不显示学号**）/ 我的
- 数据层：jsDelivr→raw 双源容错 + 本地缓存；`state.json` 优先、`feed.json` 兜底（state 空骨架时真实留痕/志愿自动读 feed）
- 交互：全页下拉刷新 + 分享卡片（小程序端）
- **权限边界**：团员端只读，不内置任何写凭据；写入仍走网页版/App 支委端（见「云端同步」）
- 打包/上架：填 appid + iOS 证书（uni-app README）、换小程序 AppID + 配 request 域名（mp README）
