# CYSL · 团支部数字化建设体系工作台

> **在线访问 → https://icyteacn.github.io/CYSL-26CS/**
> （管理口令：`cysl26`，进入后请在「体系 → 安全与隐私」修改）

面向团支部的通用数字化工作台（纯静态 SPA，零构建），与 Android「智团慧建」App 数据模型互通。
当前实例：**计算机与网络空间安全学院2026级硕士研究生1班团支部**（福建师范大学）。

## 功能

- **首页驾驶舱**：支部建设指数环形图、三会两制一课雷达图、下次活动倒计时、规范度自动巡检提醒（可点击直达处理）
- **留痕台账**：12 类活动筛选/搜索、三件套（签到表+会议记录+归档）徽章、详情页扫码签到、关联立项证据链
- **活动月历**：按月浏览活动标记，点日期看当日留痕
- **志愿服务**：时长排行 TOP10 图表、成员明细、按实登记
- **团支部立项**：申报表式字段（目标/立项依据/实施方案/成果），含「智慧留痕」示例立项
- **成员管理**：增删改查、占位姓名、政治面貌/职务标记
- **建设体系**：制度落实进度条、荣誉台账、**一键生成年度建设报告**（可打印/存 PDF）、JSON 备份导入导出
- **出片展示屏** `✦`：全屏深红金主题，三页自动轮播 + 实时时钟 + 滚动标语——支部大会/迎检时全屏投屏或全支部手机对镜头
- **签到路由**：`#/checkin?e=<记录ID>`，App 端 ZXing 生成的二维码可直接跳本站签到

## 安全与隐私

| 机制 | 说明 |
|---|---|
| 数据本地化 | 全部数据存浏览器 `localStorage`，无任何服务器上传 |
| 占位姓名 | 初始为「团员01…26 / 青年01…08」，不含真实个人信息 |
| 三级身份 | 支委/委员（可编辑，需口令）· 团员（查看+签到）· 青年群众/访客（只读） |
| 口令锁 | SHA-256 哈希校验，初始口令 **`cysl26`**（进入后请立即在「体系 → 安全与隐私」修改） |
| 脱敏模式 | 一键开启后全站姓名显示为 `X**`，公开演示前建议开启 |

## 通用化使用

其他团支部可直接 fork 本仓库 → 修改 `assets/app.js` 顶部 `BRANCH` 常量 → 部署即拥有自己的支部工作台。

## 部署

GitHub Actions（`.github/workflows/pages.yml`）推送到 `main` 即自动发布到 Pages：

- Pages 地址：`https://<用户名>.github.io/CYSL-26CS/`
- 无需 npm/构建步骤，静态文件直接部署

## 本地预览

任意静态服务器即可：`python -m http.server` / `npx serve`，或直接双击 `index.html`（部分浏览器需关闭文件协议限制，建议本地服务器）。
