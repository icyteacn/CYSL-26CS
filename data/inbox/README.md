# data/inbox/ — 变更申请审核箱

成员端「📮 提交申请」把本地数据以 `sub-时间戳.json` 文件放进本目录（GitHub 无写权限者自动走 fork + PR，支委合并 PR 即文件入库）。

支委端「✅ 审核申请」流程：

1. 列出本目录全部 `sub-*.json`
2. 逐份按业务键去重合并进本地库（记录=标题+日期，志愿=成员+活动+日期，成员=姓名+尾号，立项=名称，荣誉=标题+日期）
3. 删除已并入的申请文件
4. 把合并结果推回 `data/state.json`（正式库）

**权限边界**：拉取 `data/state.json` 全员免配置（CDN 直读）；写入一律需 GitHub 仓库权限（支委 token 直写，或无权限者经 PR 审核）——正式库不可能被未授权方直接覆盖。
